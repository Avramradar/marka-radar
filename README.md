# MarkaRadar

## Описание

MarkaRadar — интеллектуальный Telegram-бот для выбора продуктов питания.

Главная задача проекта — помогать людям выбирать лучшие продукты на основе оценок пользователей MarkaRadar, персональных предпочтений и актуальной информации о ценах.

---

## Основные возможности

- 🔍 Поиск по названию продукта.
- 🏷 Поиск по бренду.
- 📦 Поиск по штрихкоду.
- ⭐ Пользовательский рейтинг от 1 до 10.
- 💬 Отзывы пользователей.
- ❤️ Избранные товары.
- 🧠 Персональные рекомендации.
- 💰 Средняя рыночная цена.
- 📊 Минимальная и максимальная цена.
- ⚠️ Предупреждение о большом разбросе цен.

---

## Основные правила проекта

- Рейтинг формируют только пользователи MarkaRadar.
- Один пользователь может иметь одну активную оценку одного товара.
- Пользователь может изменить свою оценку.
- Цена не влияет на рейтинг товара.
- Персональные рекомендации влияют только на порядок выдачи результатов поиска.
