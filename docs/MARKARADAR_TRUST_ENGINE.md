# MARKARADAR TRUST ENGINE

## Назначение

MarkaRadar Trust Engine — это система, которая помогает человеку понять:

- стоит ли выбирать товар;
- насколько можно доверять его рейтингу;
- достаточно ли данных для рекомендации;
- есть ли среди похожих товаров более удачные варианты.

MarkaRadar не выносит категоричных приговоров без достаточных данных.

Главная задача системы — не показать цифру рейтинга, а дать понятную, честную и объяснимую рекомендацию.

---

# 1. Основные принципы

## 1.1. Рейтинг и доверие — разные показатели

Средняя оценка товара не показывает, насколько надёжен результат.

Пример:

- рейтинг 10 из 10 при одной оценке;
- рейтинг 8.8 из 10 при 500 оценках.

Второй результат значительно надёжнее, несмотря на более низкую среднюю оценку.

Поэтому MarkaRadar всегда отдельно рассчитывает:

- среднюю оценку;
- количество оценок;
- доверие к рейтингу;
- итоговую рекомендацию.

---

## 1.2. MarkaRadar никогда не угадывает

Если данных недостаточно, система прямо сообщает об этом.

Нельзя уверенно рекомендовать или не рекомендовать товар, когда:

- оценок слишком мало;
- оценки сильно расходятся;
- данные устарели;
- товар невозможно точно определить;
- информация о товаре неполная.

---

## 1.3. Каждая рекомендация должна быть объяснима

Пользователь должен понимать, почему товар получил определённый статус.

Примеры объяснений:

- высокая средняя оценка;
- большое количество голосов;
- рейтинг стабилен;
- оценки пользователей сильно расходятся;
- данных пока недостаточно;
- среди похожих товаров есть варианты с более высоким рейтингом;
- карточка товара содержит мало информации.

---

## 1.4. Система помогает выбирать, а не осуждает

MarkaRadar не использует категоричные формулировки:

- «плохой товар»;
- «не покупайте»;
- «опасный продукт»;

если для этого нет надёжных подтверждений.

Предпочтительные формулировки:

- «есть более удачные альтернативы»;
- «оценки пользователей ниже среднего»;
- «рейтинг пока недостаточно подтверждён»;
- «мнения покупателей разделились»;
- «недостаточно данных для уверенного вывода».
